# Gym Bro

Telegram-бот для новичка в зале: программа под твой инвентарь, напоминания, подсказки по весам, GIF-анимации упражнений, ИИ-тренер (Gemini + Groq), голос (Groq Whisper), честный справочник по добавкам.

**Полная пошаговая инструкция (токен, ключи, сервер, обновление, бэкап, ошибки): [docs/SETUP.md](docs/SETUP.md).**

## Запуск за 3 минуты

```bash
cp .env.example .env     # впиши BOT_TOKEN, GEMINI_API_KEY, GROQ_API_KEY
uv sync
uv run python -m bot
```

- `BOT_TOKEN` — у `@BotFather`.
- Ключи: [Gemini](https://aistudio.google.com/apikey), [Groq](https://console.groq.com/keys), оба на бесплатном тарифе.
- Без ключей бот работает, кроме ИИ-чата, голоса и разбора фото.
- Свой Telegram ID (`@userinfobot`) впиши в `ALLOWED_USER_IDS`, пока бот не для всех.
- Модель Gemini по умолчанию `gemini-3.8-flash`. Не отвечает Gemini — бот уходит на Groq. Имена моделей меняются у провайдеров: при проблемах проверь `GEMINI_MODEL` и `GROQ_*_MODEL` в `.env`.

## Что умеет

| Функция | Как работает |
|---|---|
| Анкета | Возраст, вес, рост, замеры (лентой, **4 фото или кружком**, либо пропустить), **цель кнопкой или своими словами** (объём, рельеф, сила, выносливость, гибкость, форма; можно две), уровень, **места** (зал, дом с инвентарём, улица, дом без инвентаря; можно все сразу), **инвентарь дома своими словами** («одна гантель 5 кг, турник, резинка 25 кг, эспандер 25 кг»), дни, время (**вписываешь сам**), доп. дни кардио или гибкости, **город или часовой пояс текстом** |
| Программа | Правила, не ИИ. 2–3 дня: «Всё тело A/B» по кругу. 4 дня: верх/низ. Упражнения только из того, что у тебя есть; веса дома ограничены твоими гантелями (нет тяжелее — растут повторы). Цель меняет диапазоны повторов и добавляет кардио-финишер. Новичку без турника-подтягиваний: австралийские и лопаточные |
| Напоминания | В твои дни и время: `[Начать · зал]`, кнопки других твоих мест, `[Через 30 мин]`, `[Пропуск]`. Без ответа через 45 минут — одно напоминание. Время и дни меняются **прямо в чате**: «напоминай в 19:30», «тренируюсь по пн, ср, пт» |
| «Не могу в зал» | Кнопка с другим твоим местом: тот же день, но упражнения под его инвентарь |
| Тренировка | Сначала **разминка** (по типу дня, с GIF-шагами), потом карточка упражнения одним сообщением: GIF, техника, прошлый результат, **стартовый вес по твоему весу тела**, разминочные подходы. Пишешь «8 10» текстом или голосом. Как далось: кнопкой или **словами**, ИИ понимает смысл. Слова про боль останавливают тренировку. В конце разбор тренера и **растяжка на мышцы, которые работали** |
| Кардио | Бег на улице, беговая дорожка, велосипед и велодорожки, велотренажёр, скакалка, быстрая ходьба: по тому, что у тебя есть. Новичкам бег-ходьба интервалами, пульсовая зона по возрасту, минуты растут по ответам «как далось». Дополнительные дни кардио (или растяжки, если цель «гибкость») со своими напоминаниями |
| Прогрессия | Первый заход: «легко» сразу добавляет вес (старт был оценкой). Дальше: все подходы закрыли верх диапазона и было не на пределе → +вес; мало повторов → вес меньше. Считает код |
| Замена | «Занят тренажёр» → кнопка «Заменить» на похожее упражнение |
| Серия и прогресс | `/stats`: серия, тренировки за неделю, рабочие веса, динамика замеров |
| Каталог | `/exercise присед`, `/library`: 1324 упражнения с GIF и русскими шагами |
| Добавки | **Купил:** пришли фото банки (лицо, состав, срок годности) или текст состава. Бот читает порцию и числа, проверяет белок в порции, фирменные смеси, стимуляторы, знак независимой проверки, срок годности, данные импортёра, честно пишет «есть вопросы» или «не рекомендую» и считает дозу под твой вес. **Планируешь купить:** что искать, бренды-ориентиры и где заказать в твоей стране (бюджетно / подходящее / лучшее) и как не нарваться на подделку. План приёма по весу, возрасту и цели, напоминания утром, перед и после тренировки. Подросткам 13–17 только безопасное и в малых дозах |
| Фото-прогресс | `/measure` → «Фото или кружок», `/photo_guide` (как снимать), `/progress` («было → стало») |
| ИИ-тренер | Любой вопрос текстом или голосом с контекстом профиля и тренировки. Gemini 3.8 Flash, при перегрузке запасная модель Gemini, затем Groq |
| Фото и видео | Фото еды, фото или видео (до 40 с) техники. Фото тела не анализируется |

## Безопасность для подростков

Правила в коде (`bot/services/guard.py`, `bot/services/supp_advice.py`), а не только в промпте, потому что модель можно уговорить:

- Меньше 13 лет — бот отказывает.
- **Добавки 13–17: малые дозы, но только из белого списка.** Креатин 3 г без загрузки, протеин одна порция при нехватке белка в еде, омега-3 250–500 мг, витамин D 600–1000 МЕ, мультивитамины. Дозы берутся из `data/supplements.json` (поле `teen`), ИИ их не придумывает и не меняет. Бот каждый раз советует сказать родителям.
- Подросткам закрыто: кофеин и энергетики, предтренировочные, жиросжигатели, тестобустеры, BCAA и всё остальное вне белого списка; диеты и дефицит калорий. Бот отвечает готовым текстом.
- Стероиды, SARMs, прогормоны: отказ для всех.
- Признаки расстройства питания или самоповреждения: бот советует поговорить со взрослым или врачом.
- `/delete_me` стирает все данные пользователя, включая ссылки на фото.
- Фото и кружки тела никуда не отправляются и ИИ не анализируются: хранится только ссылка на файл у Telegram, чтобы показать «было → стало». Фото еды и видео техники уходят в Gemini/Groq «на лету» и не сохраняются. Что уходит наружу: `/privacy`.

Для подростков данных меньше, чем для взрослых: исследования креатина у здоровых подростков серьёзных проблем не нашли, но официальные рекомендации осторожнее. Поэтому бот называет это справкой, а не назначением.

## Источники упражнений и лицензии

Базу упражнений бот **не копирует в проект**: он берёт её по ссылкам с GitHub, версии зафиксированы коммитами (`bot/sources.py`).

| Репозиторий | Что берём | Лицензия |
|---|---|---|
| [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset) | GIF-анимации, русские инструкции, поиск и каталог (1324 упражнения) | Данные и тексты MIT. **Анимации © Gym visual**, перераспределяются с разрешения автора репозитория. Для своего использования нужна собственная лицензия у [gymvisual.com](https://gymvisual.com/) |
| [yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db) | Запасные картинки старт/финиш, если GIF недоступен | Unlicense, общественное достояние |

**Риск:** для личного бота и друзей проблем нет. Если будешь выкладывать бот публично или зарабатывать на нём, анимации Gym visual нужно лицензировать. Без них бот продолжит работать на картинках free-exercise-db: достаточно убрать поле `hasan` из `data/exercises.json`.

Индекс (~1 МБ после сжатия) скачивается при первом запуске в `var/cache/` и дальше берётся оттуда. Нет сети и нет кэша — бот работает без GIF.

## Архитектура

```
bot/
  main.py            запуск, роутеры, ограничение доступа
  config.py          настройки из .env
  sources.py         внешние репозитории (SHA, ссылки)
  data.py            загрузка упражнений, программ, добавок
  cards.py           показ GIF и русских шагов
  photo_guide.py     инструкция по фото и кружку
  prompts.py         промпты ИИ
  ui.py              кнопки
  middlewares.py     очередь на пользователя, защита от двойного нажатия
  handlers/          onboarding, workout, info, supplements, progress, chat
  services/
    program_builder  программа по шаблону и инвентарю
    start_weights    стартовый вес по весу тела
    places           несколько мест тренировок
    intents          «напоминай в 19:30», «у меня есть креатин»
    supp_plan        план приёма добавок по весу и цели
    supp_label       проверка этикетки: порции, красные флаги, доза под тебя
    supp_shop        что и где купить по стране
    equipment        инвентарь дома, веса, ограничения
    goals            цели и диапазоны повторов
    cardio           виды кардио и протоколы
    warmup           разминка и растяжка
    location         город, страна, часовой пояс
    debrief          итог тренировки
    progression      прогрессия, подсказки после подхода
    set_parser       «40 на 10 тяжело» -> подход
    guard            жёсткие правила безопасности
    supp_advice      дозы добавок для подростков из справочника
    workout          логика тренировки
    reminders        APScheduler
    llm              Gemini (основной), Groq (запасной), Whisper
    exercise_db      клиент внешней базы
  db/database.py     SQLite
data/                свои данные: exercises.json (подсказки на русском), programs.json, supplements.json
tests/               177 тестов, включая сквозной прогон бота
```

Добавить упражнение: запись в `data/exercises.json` (паттерн, инвентарь, подсказки, `hasan` — id из базы). Новая программа: шаблоны в `data/programs.json`.

## Деплой

systemd (`deploy/gymbro.service`):

```bash
git clone <repo> /opt/gym-bro && cd /opt/gym-bro
cp .env.example .env && chmod 600 .env   # заполнить
uv sync --no-dev
sudo cp deploy/gymbro.service /etc/systemd/system/ && sudo systemctl enable --now gymbro
journalctl -u gymbro -f
```

Docker:

```bash
docker build -t gym-bro .
docker run -d --restart=always --env-file .env -v gymbro-data:/app/var gym-bro
```

База SQLite лежит в `var/gymbro.db`. Это единственное, что надо бэкапить. Бот работает через polling: входящие порты не нужны.

## Что не проверено

- Живой Telegram и реальные ключи Gemini/Groq: тесты используют подменённый Telegram, ИИ в них не вызывается.
- Как Telegram покажет GIF 180×180 из внешнего репозитория: ссылки отвечают корректно, остальное увидишь при первом запуске.
- Дозы и тексты по добавкам написаны по общеизвестным обзорам, это справка, а не медицинский совет. Если дашь бот другим подросткам, пусть врач или тренер просмотрит `data/supplements.json`.
- Три упражнения без GIF в базе (приседания без веса, супермен, планка): для них показываются картинки free-exercise-db.
